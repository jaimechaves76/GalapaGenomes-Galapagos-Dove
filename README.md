# GalapaGenomes-Galapagos-Dove
These codes were used to generate the genome of the Galapagos Dove, as reported in the publication:

**The Generation of a High-Quality De Novo Genome Assembly for the Galápagos Endemic Galapagos Dove**

Eva Driggs, James B. Henderson, Athena Lam, Jessica Martin, David Anchundia, John Dumbacher, Jaime A. Chaves

Additional collection and collaborator: Jefferson Loor.
